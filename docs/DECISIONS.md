| Learn first; Paper I first; pilot parallel circuits and a separate 2025 editorial sample | Exercises the teaching loop with existing material. Expand by reviewed coverage, not empty pages. Pharmacy needs its own owner decision and evidence. |
| Use Astro static pages, TypeScript strict, Tailwind and optional build-time Python | Direct links, rich local interactions and no server bill. Reject server-side rendering or runtime Python unless a new requirement actually needs it. |
| Preserve legacy source, don't fork its UI or import its claims wholesale | Existing records disagree in places. Keep evidence and use item-level checks. |

| Explicit PYQ ↔ lesson-section map over fuzzy automatic routing | A plausible wrong section is worse than an honest missing link. OCR is for discovery, not identification or grading. |
| Curated video + written lesson over video-only course | Works on limited data and when links die. Reviewed hints over runtime AI; no required cloud feature. |
| Publish only static output on public-repo Pages; standard Linux CI | Fits Android/Termux maintenance with no always-on host. Recheck quotas at release; stop rather than pay. |
| 2026-11-19 owner decision: independent learner transfer stays **untested**; the owner accepts continuing with clearly labelled preview/public web work rather than waiting for that evidence | Asked directly, the owner said the Phase 2 learner test was acceptable to leave untested and said it may not have been recorded in an earlier chat. This is recorded as an explicit owner waiver of the *learning-transfer claim*, not as a pass, not as evidence that a learner solved the unseen case, and not as authorization to deploy a specific build. Revisit before calling the learning path verified or making a pedagogical efficacy claim. |
| 2026-11-19 owner approval: build the real exam engine and the redesigned shell, and publish the archived PYQs and answer keys with visible provenance labels | Approved in-session. The corpus and the keys become public, so every paper carries its year, paper, set/booklet, key tier (official, derived, read only) and the board document reference, and a derived key is never labelled official. Publication permission for this corpus is granted; official-original verification of the board documents is a separate provenance question that remains open and is not asserted anywhere. |
| Publish the 2017, 2018, 2019 and 2021 papers as **read only** — no key, no scoring, no drill | Their transcribed options never reach the board's own key, so a marked paper would be a claim we cannot support. The questions are still readable and searchable, which is most of the learning value, and the held count is shown honestly. Revisit if a usable key for those years is found. |
| A question whose diagram was never transcribed is held, never scored | A figure with missing axes, labels or graphical options blocks scoring, per the editorial contract. Held items stay visible in the reader with their reason, and they are excluded from every scored pool and from the denominator of any total. |
| The search index ships as a compact v2 payload fetched at runtime, and the no-JavaScript directory lists one entry per paper | Listing all 690 questions in the static HTML added ~200 KB to one page for a fallback that every question already beats through search. The payload is 381,610 bytes raw and 59,073 bytes gzip, still one request, still same-origin. |
| 2026-11-20 owner decision: **ADR-0003 accepted** — derived answer keys use the four-tier model (`official`, `derived-verified`, `derived-provisional`, `disputed`), and only the first two may score | Recorded in [`docs/phases/09-derived-keys/DECISION-adr-0003-accepted.md`](phases/09-derived-keys/DECISION-adr-0003-accepted.md); the archive's ADR-0003 file stays byte-identical at `PROPOSED` because `archive/` is immutable. Acceptance verifies nothing: 0 entries are `derived-verified` and `eligibleCount` is 0 in all four years, so the four target papers still cannot be scored. It does expose a dated defect outside phase 09 — 13 of 2022's 87 scoreable questions are `derived-provisional` and must stop scoring in a reviewed 2022 step. Revisit if a derived key is shown wrong in a way the process could not catch, or if a board key appears for one of these years. |

Pending owner gates: publication rights, pedagogical/translation reviewers, independent archive copy, explicit go/no-go for a specific Pages deployment, and any optional account/tutor service. The 2026-11-19 waiver removes the learner-transfer blocker for labelled preview work only; it does not replace a content/rights review or a named release decision. Log future changes with date, decision owner, alternatives considered, evidence and impact on previous content/attempts.
