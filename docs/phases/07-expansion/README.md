# 07 · Grow the curriculum in reviewed batches

**Entry:** learning pilot evidence plus a reusable authoring/review process. Prioritise syllabus gaps and student difficulties, not raw question count.

- Pick the next chapter; record coverage, lesson objective, misconception, linked PYQs and review capacity. Repeat the independent transfer task. Pilot reviewed Bengali intuition, chosen videos and interactive labs where each teaches a specific concept.
- Use optional build-time Python for reproducible original variants, unit/answer checks and distractor checks. Editorial review samples edge cases; no runtime generation claims. Apply [rights and readiness standards](../../CONTENT.md) to every batch.
- Add more full papers only through the phase 05 gate. Plan revision by real activity, not predicted rank. Never extrapolate one reviewed chapter to a complete subject.

**Exit per batch:** publish dated additions, changed coverage, checked IDs/links, review evidence and remaining gaps. Do not promise a calendar deadline for complete coverage.

**Execute:** [ordered tasks and acceptance checks](RUNBOOK.md). Use the [reusable session prompt](../../../prompt.md) and [roadmap](../../ROADMAP.md) for authorization and status.
