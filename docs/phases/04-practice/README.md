# 04 · Verified practice and revision

**Entry:** approved scoreable subset, year-specific rules and local workspace. Never import raw items into a scored pool.

1. Build guided and independent sets by topic/category, notebook mode and response snapshots. Clearly identify original exercises and hint-assisted answers.
2. Show marks arithmetic and worked explanation separately. Record wrong, partial, guessed-right and slow items; optional reason tags. Blind retry first, then compare attempts and offer precise lesson links.
3. Surface coverage, independent success with denominator, and due retries separately. Offer time-budget session and reschedule missed days without false streaks.

**Exit:** run all [scoring fixtures](../../CONTENT.md), including fractions; demonstrate that unverified questions cannot enter a scored PYQ drill. Resume an interrupted set without losing selections. A student can explain a partial score, find the needed concept and solve a later retry. No inflated mastery or rank claims.

**Execute:** [ordered tasks and acceptance checks](RUNBOOK.md). Use the [reusable session prompt](../../../prompt.md) and [roadmap](../../ROADMAP.md) for authorization and status.
