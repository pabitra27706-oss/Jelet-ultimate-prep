## Proposed implementation slice (for a later IMPLEMENT chat)

1. **Outside-site instructions.** Static, plain-language steps: open Google Lens on the phone → choose the printed text → copy a distinctive line → return to this site → paste into local search → confirm the candidate by year, paper, set and printed number. Offer “enter year/number manually — no Google needed” as an equally prominent path. State that the site does not receive photos and cannot certify an answer from a picture.
2. **Local paste/search behaviour.** Reuse the 03.2 build-time index. Normalize whitespace, full-width spacing and option prefixes; preserve meaningful signs, exponents (`10^-3`), subscripts (`R₁`), units (`Ω`, `V`, `A`) and fraction markers. Score exact distinctive tokens highest, then fuzzy tokens; display candidates with year/paper/set/number rather than a single confident answer. A close but ambiguous result yields a short alternatives list; a poor match yields “No match — try a year/number filter or paste more text.” Blank input shows the instructions, not an error.
3. **Manual filters and figures.** Expose subject/topic, year, stream, category, readiness and figure filters from 03.2. A graph/figure-only prompt with no useful text has no asserted match: the student filters by year/topic or uses the reader's source link. Held and unmapped records never appear as public candidates; a figure with missing axes remains a figure-status warning, not a solved question.
4. **Privacy boundary.** No `<input type="file">`, camera permission, stored paste history, upload request, remote font or third-party script. Pasted text stays in the page's local state; nothing is written to `localStorage`, IndexedDB or a share URL by this feature. A short notice repeats this near the paste box.
5. **Synthetic fixtures (test data, not editorial claims):** `R1 = 6 Ω` vs `R₁ = 6 Ω`; exponent misread `10^-3` vs `10 3`; option prefixes `(A)` / `A.` stripped without altering numbers; two streams both printing Q72; graph-only text; blank input; a noisy string below the match threshold. These validate behaviour only; they are not evidence of a real cleared question.
