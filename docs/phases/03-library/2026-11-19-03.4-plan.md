## Proposed implementation slice (for a later IMPLEMENT chat)

1. **Local stores and lifecycle.** Versioned IndexedDB with keyed stores for bookmarks, notes, topic states, reading position, attempts, flags, due retries and settings. Keys use the immutable 03.1 IDs and existing lesson/section IDs. Persist before navigation and on `visibilitychange`; resume from a stored deadline rather than tick counts. Two tabs must not award extra time or submit twice; state that a local clock is not tamper-proof. When storage is blocked/full, show an explicit unsaved indicator and keep reading/practice usable.
2. **Attempt snapshot (structure only).** Store paper/set, rule version, content version, selected options, assistance used, timestamps and submission state when practice exists. This phase stores and transfers the record; it does not add grading, rank prediction or an official key. Assistance flags remain distinct from independent attempts and are never placed in public URLs.
3. **Export.** Produce a versioned JSON file with an app identifier, schema version, export timestamp and typed item arrays. Explain before download that the file is personal and should not be committed or shared publicly. No private value goes into a repository fixture; tests use generated synthetic IDs and strings only.
4. **Import preview and confirmation.** Before changing anything, validate JSON type, supported version, size limit, item types and IDs. Show a preview table of added/changed/removed counts and unresolved legacy entries. Require explicit **merge** or **replace** confirmation; cancel keeps the old data byte-for-byte. Dedupe by stable ID; retain unresolved entries for review rather than guessing a mapping. Do not claim old-site migration works without a consented sample and a passed round trip.
5. **Reset and duplicate handling.** A separate, explicit reset action with typed confirmation offers an export first; it never touches the archive or another origin's data. Importing the same export twice must not duplicate IDs or silently overwrite newer local notes. Failed/canceled imports leave the workspace unchanged and report why in plain language.
