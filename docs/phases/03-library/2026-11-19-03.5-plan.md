**Preconditions:** 03.1–03.4 implemented and independently verified; Phase 02 learner-transfer result recorded or explicitly accepted as untested by the owner; named editorial approval for every real record and anchor; accessibility and cost review; owner release authorization. A missing precondition is a `not passed` gate, not a caveat.

| Gate | Check on the built artifact | Failure example / result |
|---|---|---|
| Artifact allowlist | Serve only `dist/` at `/Jelet-ultimate-prep/`; enumerate emitted files; assert no archive, backup, PDF, key, note or private path. | One private file present → fail. |
| Deep links | `curl`/browser on the intended subpath: Today, Learn, chapter, question pages, old alias; refresh and pasted URL; unknown/held ID → 404. | Pasted URL returns 404 or archive path returns 200 → fail. |
| Mapping integrity | Every published forward link points to an existing immutable anchor in the named lesson; a recorded reviewer note confirms teaching relevance; reverse links agree with the same source. | Return path | On 390×844 touch, direct question → exact section → Back returns to same question/filter; desktop keyboard and no-JS variants remain usable. | Filter or question lost on Back → fail. |
| Share privacy | Default share/copy text contains metadata and canonical URL only; explicit solution variant only for a reviewed solution; no bookmark, note or chosen option anywhere in the payload or URL. | Answer or private state in default share → fail. |
