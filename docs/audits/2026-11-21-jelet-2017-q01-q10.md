### Q1 — even-order skew-symmetric determinant

**Location:** viewer 3 / printed 3. **Diagram:** none.

Printed stem: “A skew-symmetric determinant of even order is”. Options: A zero; B perfect square; C not a perfect square; D Non zero.

**Proposed answer: B — perfect square.** For a 2m × 2m skew-symmetric matrix, det(A) = Pf(A)². Zero is allowed, so “Non zero” is not universally true. For example, the 2 × 2 matrix with off-diagonal entries a and −a has determinant a².

**Assumption:** conventional real-entry or formal-polynomial usage of “perfect square,” not necessarily the square of an integer. The printed stem does not specify the field. **Transcription:** stem/options agree with fallback apart from typography. **Stored comparison:** ANSWER-NOT-CHECKABLE; record absent.

### Q2 — adjugate under scalar multiplication

**Location:** viewer 3 / printed 3. **Diagram:** none; option exponents were enlarged for inspection.

Printed stem: “If A be a n × n matrix and k be a scalar, then adj(kA) is”. Printed options:

- A: kⁿ adj(A)
- B: (1/kⁿ) adj(A)
- C: k^(n−1) adj(A)
- D: (1/k^(n−1)) adj(A)

**Proposed answer: C — k^(n−1) adj(A).** Each cofactor is a determinant of order n−1, so scaling all its entries by k multiplies it by k^(n−1). Transposition does not change that factor. This proof does not require A to be invertible; use the usual positive-integer dimension convention.

**Transcription mismatch:** archived A is `k adj(A)` (missing superscript n); archived C is `k⁻¹ adj(A)` (missing n in exponent n−1). The scan clearly prints kⁿ and k^(n−1), respectively. B/D agree mathematically. **Stored comparison:** ANSWER-NOT-CHECKABLE; do not compare a label without restoring its printed option text.

### Q3 — sum of unit-vector dot products

**Location:** viewer 3 / printed 3. **Diagram:** none.

Printed data: a, b, c are unit vectors, a+b+c=0; find a·b+b·c+c·a. Options: A 3; B −3/2; C 3/2; D −3.

**Proposed answer: B — −3/2.** Square the vector equation: 0 = |a+b+c|² = 3 + 2(a·b+b·c+c·a). Hence the requested sum is −3/2.

**Assumption:** ordinary Euclidean dot product. **Transcription:** stem/options agree mathematically. **Stored comparison:** ANSWER-NOT-CHECKABLE.

### Q4 — cyclic scalar triple products

**Location:** viewer 3 / printed 3. **Diagram:** none.

Printed expression: î·(ĵ×k̂) + ĵ·(k̂×î) + k̂·(î×ĵ). Options: A 0; B 1; C −1; D 3.

### Q5 — forward difference of a quotient

**Location:** viewer 3 / printed 3. **Diagram:** none.

Printed stem: “Value of Δ(f/g) is”. Options:

- A: (g Δf − f Δg)/[g(g+Δg)]
- B: (f Δg − g Δf)/[g(g+Δg)]
- C: (g Δf + f Δg)/[f(f−Δf)]
- D: (g Δg − f Δf)/[f(f+Δf)]

**Proposed answer: A — (g Δf − f Δg)/[g(g+Δg)].** From the forward-difference definition,

Δ(f/g) = (f+Δf)/(g+Δg) − f/g = (g Δf − f Δg)/[g(g+Δg)].

**Assumptions:** f/g is defined at both points; g and g+Δg are nonzero; Δ is the forward-difference operator. **Transcription:** stem and all four options agree mathematically. **Stored comparison:** ANSWER-NOT-CHECKABLE.

### Q6 — Simpson’s one-third rule

**Location:** viewer 4 / printed 4. **Diagram:** none.

**Proposed answer: C — 0.694.** With h=1/2, ordinates are 1, 2/3, 1/2. Simpson’s estimate is

**Assumption:** round to three decimal places as the options do. **Transcription:** no mathematical mismatch. **Stored comparison:** ANSWER-NOT-CHECKABLE.

### Q7 — Newton–Raphson root

**Location:** viewer 4 / printed 4. **Diagram:** none.

Printed question: root of x³−8x−4=0 by Newton–Raphson. Options: A 4.15; B 3.99; C 3.05; D 9.06.

**Proposed answer: C — 3.05**, for the positive root. Iteration is x_(r+1)=x_r−(x_r³−8x_r−4)/(3x_r²−8). Starting at 3 gives 3.05263158, then approximately 3.05137497, converging to 3.05137424; to two decimals, 3.05.

**Assumptions/caveat:** the printed question specifies neither initial guess nor root interval; the cubic has three real roots (its two stationary values straddle zero). The options contain only positive numbers, and only C approximates the positive root. The chosen initial value is an explicit solver assumption, not printed data. **Transcription:** no mathematical mismatch. **Stored comparison:** ANSWER-NOT-CHECKABLE.

### Q8 — trapezoidal rule: no option fits

**Location:** viewer 4 / printed 4. **Diagram:** none.

Printed question: ∫₀¹ dx/(1+x), “by Trapezoidal rule by taking five ordinates”. Printed options: A 0.793; B 0.693; C 0.593; D 0.513. The scan spells the method “Trapizoidal”; that spelling does not alter the calculation.

**Proposed answer: no matching option.** Five ordinates mean four equal subintervals, h=1/4. The ordinates are 1, 4/5, 2/3, 4/7, 1/2. Thus

T = (1/4)[(1+1/2)/2 + 4/5 + 2/3 + 4/7] = 1171/1680 = 0.6970238095…,

**Assumption:** standard equal-spacing trapezoidal rule; nonuniform abscissae are not supplied. **Transcription:** the numerical stem and all options match the archived fallback, so this is a printed-method/option conflict, not an identified transcription error. ### Q9 — Gaussian-elimination operation count

**Location:** viewer 4 / printed 4. **Diagram:** none.

Printed question: total multiplications and divisions to solve n linear equations in n variables by Gauss elimination. Options:

- A: n³/3 + n²/2
- B: n³/3 − n/3
- C: n³/3 + n² − n/3
- D: n³/3 − n²/2 + n/3

**Proposed answer: C — n³/3 + n² − n/3.** Count elimination of a dense coefficient matrix plus its right-hand side, followed by back substitution. With m rows below the pivot, each row uses one division for the multiplier, m multiplications for remaining coefficients and one for the right-hand side: m(m+2) operations per stage. Therefore elimination costs

Σ_(m=1)^(n−1) m(m+2) = (2n³+3n²−5n)/6.

Back substitution adds n(n−1)/2 multiplications and n divisions, i.e. n(n+1)/2. The sum is n³/3+n²−n/3.

**Assumptions:** conventional dense, unnormalised forward elimination; known-zero pivot-column entries are assigned zero rather than recomputed; count multiplications/divisions only, include right-hand-side updates and back substitution, exclude pivot-search comparisons and additions/subtractions. Different algorithm conventions change exact lower-order counts, so the convention is part of the answer. **Transcription:** stem/options agree mathematically. **Stored comparison:** ANSWER-NOT-CHECKABLE.

### Q10 — degree and order: fourth root, not four times a square root

**Location:** viewer 4 / printed 4. **Diagram:** none. The radical was enlarged and visually checked.

Printed equation: d²x/dt² − ⁴√[x+(dx/dt)²] = 0. The small **4 is the radical index**, not a coefficient. The question asks for **degree and order**, in that order. Options: A 4, 2; B 2, 4; C 4, 3; D 2, 2.

**Proposed answer: A — 4, 2.** Eliminate the fourth root to obtain (x″)⁴ − x − (x′)²=0. The highest derivative is x″ (order 2); its exponent in the resulting polynomial differential equation is 4 (degree 4). The real principal-root equation additionally restricts x″≥0; that branch restriction does not alter this conventional degree/order classification.

**Transcription mismatch:** the archived stem writes `4\sqrt{...}` (four times a square root), which would instead yield degree 2 and option D. This is answer-affecting, not cosmetic. The printed equation must be the basis of the audit. **Stored comparison:** ANSWER-NOT-CHECKABLE; no claim is made about which option the absent import stores.
